# Incorporation document tools

Browser-based tools that fill the firm's standard incorporation formats from one set of inputs.
Open the `index.html` of the tool you need by double-clicking it; nothing is uploaded anywhere.

| Folder | Tool |
|---|---|
| `llp-docs/` | LLP incorporation: Form 9, consent letter, subscription sheet, NOC, LLP Agreement, data sheet, print set |
| `company-docs/` | Private Limited Company and One Person Company: NOC, data sheet for SPICe+ (e-MoA / e-AoA) |
| `shared/` | Code used by both tools – keep it next to the tool folders |

Each tool's own README explains its inputs, checks and templates.
