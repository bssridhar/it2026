Checklists and Procedures

Standard lists of documents and procedures for clients – Income-tax, GST, ROC, General. Copy one or more into an email with the formatting. Archive what is out of date: it stays in the Archive tab for reference and cannot be copied by mistake.

Keep the library file in a shared folder: open it there, and Save writes the changes back into it, so the whole team uses the same list. The library is also kept in this browser between visits.

You can paste from Word, Zoho Writer or Google Docs – headings, lists, bold, links and tables are kept; colours and fonts are dropped so that every email looks the same.

Bulk add links

One link per line. To give a title, write it before the link with a "|": Payment of advance tax | https://…. Lines without a title get a provisional one – rename them afterwards.

Categories

A category can be deleted only when it has no items (active or archived). Renaming moves its items.
