# Checklists and Procedures

Standard lists of documents / information and procedures that clients ask for, and links to the firm's own documents
(Zoho Writer / WorkDrive / Sheet, Google Docs, portal pages), kept by category: Income-tax, GST, ROC, General (add more
under **Categories…**).

- **Copy for email** – copies the item with its formatting (headings, numbered lists, bold, links, tables) for pasting
  into Gmail / Outlook / Zoho Mail. Options: start with "Dear <name>," and show the title as a heading. Tick several
  items to copy them together.
- **New item / Edit** – a text editor with headings, lists, links and tables; pasting from Word / Zoho Writer / Google
  Docs keeps the structure and drops colours and fonts. Each item can have "Valid for" (e.g. AY 2026-27) and a
  "Review by" date – after that date it is flagged "Review due" and copying asks for confirmation.
- **Link items** – a title, the link and an optional description. **Bulk add links**: paste one link per line, with
  an optional title before a "|".
- **Archive** – moves an outdated item to the Archive tab, still under its category, for reference. Archived items are
  not shown in the Active tab, and copying one asks for confirmation. **Restore** brings it back; **Delete** is only
  in the Archive tab. **Duplicate** makes a copy to edit – e.g. next year's version before archiving this year's.
- **Library file** – Save library / Save as / Open library (JSON). Keep it in a shared folder so that the team works
  from the same list; the library is also kept in the browser.

The starter items are general text – review and edit them to the firm's practice before use.
